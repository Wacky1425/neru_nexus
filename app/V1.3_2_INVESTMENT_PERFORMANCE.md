# V1.3-2 Investment Performance Decomposition

Implemented:
- Derive investment cash contributions from confirmed transfer rows.
- Count non-investment -> investment as positive contribution.
- Count investment -> non-investment as withdrawal (negative contribution).
- Ignore investment -> investment internal transfers.
- For each snapshot interval:
  investment return = investment asset change - net contribution.
- Asset Trend API now returns a range-level `investmentPerformance` summary.
- Each trend item receives `periodContribution` and `periodInvestmentReturn`.
- Asset Trend UI displays investment change, cash contributed, investment return,
  and an approximate return rate.
- Existing R_AssetSnapshots columns are unchanged.

Important:
- This depends on transfer rows having correct `from_account` and `to_account`.
- The displayed return rate is intentionally a simple approximation and is not
  TWR or XIRR.
