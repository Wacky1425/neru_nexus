# V2.2-2 要確認・取込UX

## 2026-09-16 first implementation

- 要確認画面を「要判断」と「正式明細待ち」に分離。
- 正式明細待ちはユーザーが分類する対象ではなく、正式CSVとの自動照合待ちとして説明。
- 画面上部に両キューの件数を表示。
- 最新CSV取込履歴を「取込監査」カードとして表示し、取込画面へ直接遷移可能にした。
- 各行に日付、カテゴリ、取込元、確認理由を表示。
- GAS review_transactions に queueMode=formal_wait を追加。既存 user_review がデフォルトなので後方互換。

次段階候補: 取込バッチ詳細監査、速報→正式明細の照合履歴、要確認理由のより細かな分類。
