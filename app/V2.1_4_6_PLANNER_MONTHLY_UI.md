# V2.1-4.6 Planner Monthly UI

- Planner is explicitly month-based: previous/next month selector + per-holding scheduled amount editor.
- Scheduled investment and discretionary capacity remain independent.
- Existing September 2026 S&P500 plan remains 30,000 JPY planned / 30,000 JPY actual / 0 remaining.
- Future months start empty and can be configured from the app when the user decides the next contribution after campaign conditions finish.
- UI never sends securities orders; it only saves Neru Nexus planning data.
