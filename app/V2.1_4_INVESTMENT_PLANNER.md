# Neru Nexus V2.1-4 Investment Planner

## Status
Implementation: 90% — code complete, real GAS/Flutter verification pending.

## Added
- Monthly investment planning by registered holding.
- Household-derived "recommended investable amount" reuses existing Neru Nexus money allocation (`totalNisa`), instead of inventing a second safety formula.
- Planned / SBI actual / remaining amount summary.
- Automatic reconciliation from SBI investment events:
  - only `status=applied`
  - only `side=buy`
  - matching `applied_holding_id`
  - matching target month
  - duplicate `event_id` excluded
  - sells are not counted as new investment contributions
- NISA / taxable plan label. No legal annual NISA limit is hardcoded.
- Plan creation, editing, soft deletion.
- One active plan per `year_month + holding_id`.
- `T_InvestmentPlans` is created automatically; no destructive spreadsheet migration.
- API v2 routes for get/save/deactivate.
- Public verifier: `verifyV214InvestmentPlanner()`.
- `runReleaseChecks()` includes V2.1-4 verification.
- Regression helper: `testInvestmentPlannerHelpers_()`.
- Flutter Investment Planner page accessible from investment portfolio screen.

## Safety / scope
- This is a planning and reconciliation feature only.
- It does not place brokerage orders or automate SBI website actions.
