# V2.1-1 Home Forecast Correctness

This patch fixes correctness debts in the V1.4 forecast logic.

## Main fixes

1. Fixed expense projection now respects the configured fixed-expense budget.
2. Card-payment cash alerts no longer subtract upcoming card payments twice.
3. Safe daily spending is capped by both remaining variable budget and available liquid cash after goal/card reserves.
4. A zero-yen safe daily amount is shown instead of silently hiding the row.

## Verification

GAS:
`runReleaseChecks()`

Flutter:
`flutter test`
`flutter analyze`

Then open Home once and check the forecast/recommendation card.

No migration is required.
