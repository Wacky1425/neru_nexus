# V2.0-5 Backend Boundary

## What changed

The app still stores data in Google Spreadsheet. V2.0-5 does not move production data.

Instead, it creates a persistence boundary so that:
- API v2 does not expose spreadsheet details.
- Flutter does not know the storage implementation.
- repository writes use header names instead of physical column positions.
- transaction updates preserve columns unknown to the current domain record.
- a future database implementation can replace the persistence driver behind GAS/API v2.
