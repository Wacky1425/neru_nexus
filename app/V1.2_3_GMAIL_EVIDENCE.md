# V1.2-3 Gmail Receipt / Evidence Intake

Implemented:
- Conservative Gmail receipt candidate scan (90 days manual, 7 days daily trigger)
- Parses receipt-like Japanese/English subjects and bodies
- Extracts amount/date/merchant
- T_GmailEvidenceCandidates auto-created; no manual spreadsheet migration
- Message-ID dedupe
- Exact-amount + date-proximity + merchant-similarity proposed matching
- Ambiguous matches are kept for review
- App approval writes Gmail permalink into T_Transactions.evidence_url
- Existing different evidence_url is never overwritten
- Ignore flow
- Regression coverage
- Daily 06:00-ish Apps Script trigger registration via runReleaseChecks()

Important:
- This phase intentionally does not create transactions from receipt mail.
- It intentionally does not auto-attach evidence without user approval.
- Actual mail templates vary by service; live Gmail scan is the final validation step.
