# V2.0-4 Device Authentication

## Normal first-time pairing

1. Deploy the V2.0-4 GAS build.
2. Run `runReleaseChecks()`.
3. Run `createV204PairingCode()` manually in Apps Script.
4. Copy the 8-digit code from the execution result/log.
5. Install/run the V2.0-4 Flutter build.
6. Enter the code within 10 minutes.
7. The app stores the returned device token in secure storage.

## Public manual GAS functions

- `createV204PairingCode()` — create one-time 8-digit code
- `verifyV204Auth()` — optional standalone auth architecture verification
- `listV204Devices()` — list paired devices without exposing token hashes
- `revokeAllV204Devices()` — emergency lost-device revocation
- `runReleaseChecks()` — full release verification

All manual entry points intentionally have no trailing underscore.

## Compatibility

Old API v1 Flutter builds continue using the existing `NERU_API_KEY` Script Property.
The new API v2 Flutter build contains no permanent API key and uses device pairing instead.
