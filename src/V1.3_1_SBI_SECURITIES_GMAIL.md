# V1.3-1 SBI Securities Gmail -> Holdings

Implemented:
- Gmail scan for SBI Securities trade notifications
- Conservative parser for buy/sell, trade date, name/code, quantity, price, amount
- T_SbiInvestmentEvents auto-created
- Gmail message ID dedupe
- Holding match by exact symbol / normalized name
- Ambiguous or unmatched events remain review-only
- Flutter review page reachable from Investment Portfolio
- Explicit apply button required before holdings are modified
- Buy: increase quantity and recalculate weighted average cost
- Sell: decrease quantity, preserve average cost, reject oversell
- Daily scan trigger registration via runReleaseChecks()
- Parser regression test

Important:
- No holding is changed merely because Gmail contains a matching message.
- No new holding is auto-created from mail.
- Actual SBI mail templates are still the final validation point.
